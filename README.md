# Лабораторная работа №6: Некоторые служебные и технологические задачи

## 1. Общие сведения
* **Дисциплина:** Операционные среды и системное программирование (ОСиСП).
* **Вариант:** №22 (Раздел Д: Работа с журналами Windows — «Запись событий учебного приложения в Windows Event Log»).
* **Журнал назначения:** `Application` («Приложение»).
* **Имя источника:** `OSiSP_Lab06_Source_095`.
* **Базовый Event ID:** `1095` (1000 + STUDENT_ID, где STUDENT_ID = 95).

## 2. Назначение приложения
Консольная служебная утилита для ОС Windows, демонстрирующая взаимодействие с системной службой ведения журналов событий Windows Event Log API.
Реализовано:
1. Запись событий трех обязательных уровней: `Information` (код 1096), `Warning` (код 1097), `Error` (код 1098).
2. Формирование 5 строк подстановки: идентификатор, временная метка, тип операции, статус результата, детали.
3. Опциональная регистрация/удаление источника в системном реестре (`--register` / `--unregister`).
4. Автоматизированный бенчмарк серийной записи (10, 50, 100 событий) с оценкой пропускной способности.

## 3. Сборка и запуск
* Сборка в Visual Studio: открыть `LW6.sln` и нажать `Ctrl+Shift+B`.
* Обычный запуск (не требует прав администратора):
  ```cmd
  LW6.exe
  ```
* Запуск с регистрацией источника в реестре (требуется запуск от имени Администратора):
  ```cmd
  LW6.exe --register
  ```
* Просмотр записанных событий:
  `Win + R` -> `eventvwr.msc` -> Журналы Windows -> Приложение -> Источник OSiSP_Lab06_Source_095
